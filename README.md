# 放課後Link

地域の未利用スペース（企業の空き会議室・自治体の公共施設など）を中高生向けの学習スペースとして活用する構想を表現したWebプロトタイプです（高校地理授業の4分間プレゼンテーション用）。

> 注意: 掲載されている施設名・企業名・地域統計データはプレゼンテーション用の**仮想デモデータ**であり、実在する企業・自治体との契約を示すものではありません。

## 主な機能
- 白基調のLiquid Glass UI（フォント: Zen Kaku Gothic New）
- 施設検索・複数条件絞り込み・MapLibre GL JS（OpenStreetMap / 地理院タイル / オフライン簡易SVG自動切替）
- Cloudflare D1 による施設・予約・お気に入り管理（原子的クエリによる二重予約・定員超過防止）
- Google OAuth 2.0 / OIDC ログイン（管理者権限のサーバー側検証）
- 愛知県内の学習場所「地域格差マップ」
- 企業・自治体の施設提供シミュレーション（前後比較の即時アニメーション反映）
- 4分間プレゼンテーション専用モード（`/demo`・キーボード操作・タイマー・オフライン耐性）
- Cloudflare Workers AI 自然言語検索（無料枠上限ガード＆フォールバック付き）
